# 🦌 Deer Adventure 2D

A pixel art 2D platformer game featuring a llama character navigating through a beautiful forest mountain landscape.

![Game Preview](preview.png)

## 🎮 How to Play

- **Move Left**: `A` or `←` Arrow
- **Move Right**: `D` or `→` Arrow  
- **Jump**: `W`, `Space`, or `↑` Arrow
- **Mobile**: Use on-screen touch controls

## 🎯 Objectives

- Collect all golden coins 🪙
- Avoid spikes and enemies 🍄
- Reach the flag at the end of the level 🚩

## ✨ Features

- **Pixel Art Style** - Retro 8-bit aesthetic
- **Parallax Background** - Multi-layered forest mountain scenery
- **Smooth Animations** - Idle, run, and jump sprite animations
- **Particle Effects** - Dust particles on landing and jumping
- **Fireflies** - Ambient floating light particles
- **Smart Enemies** - Mushroom enemies with chase AI
- **Mobile Support** - Touch controls for mobile devices
- **Lives System** - 3 lives with health display

## 📁 Project Structure

```
deer_adventure2d/
├── index.html              # Main game file
├── README.md               # This file
├── assets/
│   └── sprites/
│       ├── idle/           # Idle animation frames (9 frames)
│       ├── run/            # Run animation frames (6 frames)
│       └── jump/           # Jump sprite (1 frame)
```

## 🚀 Getting Started

1. Clone this repository
2. Open `index.html` in a web browser
3. Start playing!

```bash
git clone https://github.com/ariebagasazzy/deer_adventure2d.git
cd deer_adventure2d
# Open index.html in your browser
```
